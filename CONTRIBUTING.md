# 🤝 Contributing to A.R.E.S.

Thank you for your interest in contributing to **A.R.E.S. (Adaptive Reasoning & Execution System)**!

A.R.E.S. is an autonomous, private, voice-enabled executive terminal AI companion conceived and exclusively owned by **Khalid Abdullah**. While the project is source-available and protected against commercial cloning, community contributions such as local model adapters, neural voice enhancements, platform compatibility, and bug fixes are welcome.

---

## 🛠️ Contribution Workflow

1. **Open an Issue:** Discuss architectural adjustments or proposed integrations first.
2. **Fork the Repo:** Create a fork and a new branch:
   ```bash
   git checkout -b feature/improvement-name
   ```
3. **Commit & Test:** Write clean, modular Python and test locally with Ollama.
4. **Submit a Pull Request (PR):** Describe the change and provide sample CLI interaction logs.
